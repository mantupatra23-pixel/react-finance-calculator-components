## 📦 Key Features

- **⚡ Zero Server Latency:** 100% client-side evaluation with instant interactive feedback.
- **🔒 Privacy First:** No financial inputs, salaries, or invoice amounts are stored or transmitted.
- **📐 Mathematical Parity:** Unified calculation engines ensure deterministic accuracy across all edge cases.
- **📱 Fully Responsive:** Clean layout designed for mobile, tablet, and desktop screens using Tailwind CSS.
